# InstaView Chrome Extension

Download Instagram stories, reels, posts, and carousels directly on `instagram.com` with a single click.

## Features
- **In-Page Download Buttons**: Injects seamless download buttons under any feed post, reel, or story on `instagram.com`.
- **Private Account Media**: Because it runs inside your logged-in browser session, you can download stories and photos from private accounts that you follow!
- **Zero Config**: Plug-and-play Manifest V3 extension.

## How to Test / Load in Chrome, Brave, or Edge
1. Open your browser and navigate to `chrome://extensions` (or `brave://extensions` / `edge://extensions`).
2. Toggle on **Developer mode** in the top-right corner.
3. Click the **Load unpacked** button in the top-left.
4. Select this `extension` folder (`d:\Kevin\Projects\Personal Projects\insta-view\extension`).
5. Open [instagram.com](https://www.instagram.com) — you will now see **⬇ Download** buttons under posts and reels, and a **⬇ Download Story** button on active stories!

## How to Publish to Chrome Web Store
1. Compress the contents of this `extension` directory into a `.zip` file (`instaview-extension.zip`).
2. Go to the [Chrome Developer Dashboard](https://chrome.google.com/webstore/devconsole).
3. Click **Add new item** and upload the `.zip` file.
4. Fill in the store description and publish!
